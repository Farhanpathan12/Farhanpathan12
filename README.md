### 🚀 Featured Projects

#### 1. [LogPulse](https://logpulse.vercel.app/) — *In-App Changelog & Reader Analytics Platform*
> Embeddable changelog SaaS that empowers product teams to publish rich release notes, embed customizable notification widgets, capture subscriber feedback, and track readership analytics.

- 🌐 **Live Demo:** [logpulse.vercel.app](https://logpulse.vercel.app/)
- 💻 **Source Code:** [github.com/Farhanpathan12/Logpulse](https://github.com/Farhanpathan12/Logpulse)
- ⚙️ **Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS, Prisma ORM, PostgreSQL, Clerk, Recharts, Resend
- ✨ **Key Highlights:**
  - Standalone embeddable widget loader (`widget.js`) with custom origins & brand theming
  - Full-featured TipTap WYSIWYG editor with scheduled publishing and tags (`NEW`, `IMPROVED`, `FIXED`)
  - Real-time reader impression counters, click rates, and historical analytics charts
  - Subscriber email broadcast delivery pipeline via Resend

#### 2. [PGH Gaming Hub](https://pgh-gaming-hub.vercel.app/) — *C2C Gaming Gear Marketplace & Trading Platform*
> Full-stack peer-to-peer marketplace connecting gamers to buy, sell, and negotiate consoles, PC components, and games with AI-assisted verification.

- 🌐 **Live Demo:** [pgh-gaming-hub.vercel.app](https://pgh-gaming-hub.vercel.app/)
- 💻 **Source Code:** [github.com/Farhanpathan12/gaming-hub](https://github.com/Farhanpathan12/gaming-hub)
- ⚙️ **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, Supabase (Auth, Realtime, DB), Google Gemini API, Leaflet
- ✨ **Key Highlights:**
  - AI Box Scan powered by Google Gemini computer vision to extract hardware specs and model numbers from packaging
  - Real-time chat negotiation with formal buyer-seller counter-offer mechanics on Supabase Realtime
  - Automated AI content moderation endpoint to protect users against scam attempts & abuse
  - Dynamic gear valuation wizard and FPS performance benchmark estimator
